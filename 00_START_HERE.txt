================================================================================

✓ Connects to your OpenStack cloud
✓ Lists all VMs with their resources (cores, storage, etc.)

✓ Calculates monthly OpenStack costs

================================================================================
  KEY FACTS
================================================================================

Pricing (Monthly):
  - Instance: $5.46/month per VM
  - Core: $5.03/month (non-GPU cores only!)
  - Storage: $0.14/GB/month
  - A100 GPU: $546.45/month
  - V100 GPU: $291.34/month

GPU Handling:
  - A100 has 24 cores (not added to CPU count)
  - V100 has 8 cores (not added to CPU count)
  - Detected from VM names (a100, v100, gpu)

Cost Comparison:
  - Shows OpenStack cost
  - Shows equivalent AWS cost
  - Shows savings/additional cost

================================================================================
  TROUBLESHOOTING
================================================================================

Problem: "Error: Could not parse OpenStack server list"
Solution: Verify OpenStack CLI is installed and credentials are configured
  Test: openstack --os-cloud=aifarms server list

Problem: GPU not detected
Solution: Check VM name contains 'gpu', 'a100', or 'v100'
  Example: gpu-ml-01, a100-server, v100-training ✓

Problem: Costs seem wrong
Solution: Check core count (GPU cores NOT included), storage in GB, floating IPs
  Formula: (cores × 5.03) + (storage × 0.14) + gpu_cost + 5.46 (instance)

Problem: Can't install dependencies
Solution: Make sure you're in the rate-calc directory
  Try: pip install --upgrade pip && pip install -r requirements.txt
